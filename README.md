# 보안관제Lite — 간단 버전 1.1

현재 PC의 통신을 보고 **정상 / 주의**로 표시하는 작은 Windows 졸업작품입니다.

## 사용법

GitHub 저장소는 소스코드를 제공합니다. 아래 **소스 실행 및 테스트** 절을 따라 실행하거나 **실행 파일 만들기** 절로 EXE를 만들 수 있습니다.

배포 ZIP을 전체 압축 해제하고 `SecurityLiteSimple.exe`를 실행합니다. `_internal` 폴더도 그대로 두세요.

1. **모니터링 시작**을 누릅니다.
2. PC 전체 송신·수신 속도와 현재 TCP 연결을 확인합니다.
3. 주의로 표시된 통신의 이유를 확인합니다.
4. **모니터링 중지**를 누르면 마지막 목록을 유지합니다.

화면은 하나이며 설정 화면, DB, 외부 API, 로그 입력 기능은 없습니다. 시작 전에는 통신 정보를 수집하지 않습니다. 수집한 주소와 프로그램 목록은 파일로 저장하거나 외부로 전송하지 않습니다.

## 무엇을 확인하나요?

| 표시 | 뜻 |
|---|---|
| 송신·수신 KB/s | PC 전체 네트워크의 약 2초 간 평균 사용량 |
| 프로그램 (PID) | 연결을 사용하는 프로그램 이름과 프로세스 번호 |
| 내 PC / 상대 주소 | TCP 연결의 IP와 포트 |
| 연결 상태 | ESTABLISHED는 연결 중, TIME_WAIT는 종료 대기 등 |
| 정상 / 주의 | 아래 단순 규칙의 결과 |

TCP 연결은 양방향으로 데이터를 주고받을 수 있습니다. 상대 주소만으로 송신/수신 방향을 단정하지 않으며, 송수신량은 위의 합계로 표시합니다. UDP 트래픽은 합계 사용량에는 포함되지만 개별 연결 목록에는 표시하지 않습니다. VPN/가상 어댑터 환경에서는 같은 트래픽이 합계에 중복 집계될 수 있습니다.

종료 대기 등으로 소유 프로그램을 알 수 없는 연결은 `소유 프로그램 미상 (?)`으로 표시합니다. 자동 갱신 중에도 선택한 연결이 남아 있으면 선택 상태가 유지됩니다. 중지 후 다시 시작하면 이전 목록을 비우고 새로 수집합니다.

## 판정 규칙은 두 가지입니다

- FTP/Telnet 포트(21, 23)를 사용하면 **주의**: 평문 통신인지 확인합니다.
- 공인 IP와 파일 공유/원격 데스크톱 포트(445, 3389)로 통신하면 **주의**: 의도한 연결인지 확인합니다.

내 PC 내부 통신은 정상으로 표시합니다. 그 외는 **현재 규칙에 해당하지 않는다**는 의미로 정상입니다. 포트는 실제 서비스를 보장하지 않고, 주의 판정이 공격이라는 뜻도 아닙니다. HTTPS 등 정상 표시된 연결에도 악성 통신이 있을 수 있습니다. 이 프로젝트는 바이러스 백신이나 패킷 내용 기반 침입탐지 프로그램이 아닙니다.

## 작은 프로젝트 구조

```text
main.py          화면과 시작/중지
monitor.py       실제 연결 및 송수신량 수집
rules.py         정상/주의 판정 규칙
test_simple.py   핵심 동작 테스트
test_gui.py      시작·중지 및 화면 회귀 테스트
build.py         실행 파일 만들기
```

Python + Tkinter + psutil만 사용합니다. 주기적 수집, 간단한 조건문, 표 출력에 집중한 범위입니다. DB, 정책 편집, 국가 조회, 공격 유형 분류, 방화벽, Docker는 제외했습니다.

## 소스 실행 및 테스트

Windows Python 3.12 이상(Tkinter 포함)에서 프로젝트 폴더를 엽니다.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
.\.venv\Scripts\python.exe -m unittest -v test_simple
.\.venv\Scripts\python.exe -m unittest -v test_gui
```

실제 GUI와 수집 확인:

```powershell
.\.venv\Scripts\python.exe main.py --smoke-test --report smoke.json
```

스모크 테스트는 PC 내부에 임시 TCP 연결을 만들고 연결 표시와 두 번의 연속 갱신·속도 표시를 확인한 뒤 종료합니다. 인터넷의 다른 서버로 테스트 패킷을 보내지 않습니다. 결과 파일 경로가 잘못되어 저장에 실패해도 창과 테스트 연결을 정리하고 실패 코드로 종료합니다.

실행 파일 만들기(Windows에서):

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller==6.22.3
.\.venv\Scripts\python.exe build.py
```

`dist/SecurityLiteSimple` 폴더 전체가 배포본입니다.

## 한계

2초 사이에 생성·종료된 짧은 연결은 놓칠 수 있습니다. 프로세스가 종료되었거나 권한이 부족하면 프로그램명이 조회 불가로 표시됩니다. 원격 주소가 없는 대기 소켓은 목록에서 제외합니다. 연결별 전송량, UDP 상대 추적, 패킷 내용 분석, 자동 차단, 기록 저장은 제공하지 않습니다.

구현에 사용한 [psutil 공식 네트워크 API](https://psutil.readthedocs.io/stable/#network)를 참고할 수 있습니다.
